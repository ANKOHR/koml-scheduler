# Build lessons

The domain requires separate agent and tool capacity checks: either can prevent an otherwise capable pair from accepting work. Resource availability here means declared remaining budget, not observed liveness.

Validated by synthetic evidence: a deterministic greedy allocation policy can reconcile all 200 task outcomes and both resource budgets exactly. Changing one task capability changes the computed reason counts, which validates that reports are derived from input rather than planted expectations.

Unvalidated assumption: Henry will find greedy priority allocation useful for real fleet supervision. No real-use accuracy, adoption, revenue, or savings evidence exists yet. The two-week trial must test this assumption.

Operating rule for future builds: define the allocation policy and independent expected task IDs before measuring aggregate success. Correct totals can conceal wrong assignments.
